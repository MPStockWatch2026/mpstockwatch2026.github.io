Privacy Policy – StockWatch Backup

Last updated: 21 November 2026

Who uses this app

StockWatch Backup is used only by its owner, for the owner's own Google account. It is not available to anyone else.

What Google data it accesses

With the owner's permission, the app uses the Google Drive API to upload backup files into one folder in the owner's own Google Drive, and to read back the file names, sizes and checksums of those files to confirm each backup is complete and undamaged.

How the data is used

  • Only to create and verify backups of the owner's own StockWatch files.
  • The app never deletes Drive files. Older copies are kept.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.

Storage and security

The Google sign-in key is stored only as an encrypted secret in the owner's private GitHub repository, where the automatic backup runs. It is never published.

Removing access

Access can be withdrawn at any time at Google Account – Third-party connections.
